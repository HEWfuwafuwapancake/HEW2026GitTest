# DX11 基盤の構成

授業（DX21）のひな形をもとに、3D ゲームを作り始められるようにした土台です。
起動すると、空・地面・回る立方体・左上の半透明パネル（2D）が表示されます。

## 操作
| キー | 動き |
|---|---|
| ← → | カメラが左右に回る |
| ↑ ↓ | カメラが上下に回る |
| W / S | カメラが近づく・離れる |
| ESC | 終了 |

## ファイルの役割
| ファイル | 役割 |
|---|---|
| `main.cpp` | ウィンドウ作成、メインループ、全体の初期化・更新・描画の順番 |
| `dx11.h / .cpp` | DirectX 11 の初期化（デバイス、画面、深度バッファ）。`VERTEX_3D` もここ |
| `shader.h / .cpp` | シェーダーの読み込みと、行列・マテリアル・ライトをシェーダーに渡す関数 |
| `shaderCommon.hlsli` | シェーダー共通の定義（定数バッファ、入出力の形） |
| `shaderVertex3D.hlsl` | 頂点シェーダー（座標変換とライトの計算） |
| `shaderPixel3D.hlsl` | ピクセルシェーダー（色を決める。テクスチャにも対応） |
| `camera.h / .cpp` | カメラ（ビュー行列・プロジェクション行列） |
| `keyboard.h / .cpp` | キーボード入力（押している／押した瞬間／離した瞬間） |
| `field.h / .cpp` | 地面のサンプル |
| `cube.h / .cpp` | 立方体のサンプル（インデックスバッファを使う例） |
| `polygon2D.h / .cpp` | 2D（UI）描画のサンプル |
| `debug_ostream.h / .cpp` | `hal::dout << "文字" << std::endl;` で VS の出力ウィンドウに表示 |

## 新しいオブジェクトを足すとき
`cube.cpp` をコピーして作るのがいちばん早いです。

1. `〇〇Initialize / Finalize / Update / Draw` の4つの関数を作る
2. `main.cpp` の `Initialize`・`Finalize`・`Update`・`Draw` から呼ぶ
3. `Draw` では次の順番で設定してから描く
   - `Shader_SetWorldMatrix(...)` … 位置・回転・大きさ（拡大縮小 → 回転 → 移動 の順に掛ける）
   - `Shader_SetMaterial(...)` … 色
   - 頂点バッファ（とインデックスバッファ）をセットして `Draw` / `DrawIndexed`
4. ファイルを Visual Studio のプロジェクトに追加する（`.vcxproj` が変わるので一緒にコミット）

## 描画の順番（`main.cpp` の `Draw`）
1. `Clear()` で画面と深度バッファを消す
2. **3D**：`SetDepthEnable(true)` → `CameraDraw()` → ライトON → 3Dオブジェクトを描く
3. **2D（UI）**：`SetDepthEnable(false)` → ライトOFF → 2Dを描く（描いた順に上に重なる）
4. `Present()` で画面に出す

## 気をつけること
- **ポリゴンの表は時計回り。** 見る側から見て頂点が時計回りに並んでいない面は描かれません（バックフェースカリング）。
- **シェーダーの定数バッファ**は `shader.h` の構造体と `shaderCommon.hlsli` の並びをそろえること。片方だけ変えると色や位置がおかしくなります。
- **シェーダー（`.hlsl` / `.hlsli`）は BOMなしUTF-8** で保存する。BOM があるとコンパイルが `X3000: Illegal character` で失敗します。
  C++ のファイル（`.cpp` / `.h`）は **BOM付きUTF-8**。
- ビルドすると `shaderVertex3D.cso` / `shaderPixel3D.cso` がプロジェクトのフォルダにできます（Git には入れない）。
  exe を直接ダブルクリックすると .cso が見つからずエラーになるので、Visual Studio から実行してください。

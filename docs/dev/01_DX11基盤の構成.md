# DX11 基盤の構成

授業（DX21）のひな形をもとに、3D ゲームを作り始められるようにした土台です。
起動すると、丘に囲まれた湖・湖の上で回る立方体・左上の半透明パネル（2D）が表示されます。
カメラはマウスとキーボードでワールドの中を自由に動けます。

## 操作
| 操作 | 動き |
|---|---|
| マウス | 見回す |
| W / A / S / D | 前・左・後ろ・右に移動 |
| Space / Ctrl | 上昇 / 下降 |
| Shift（押しながら） | 速く移動 |
| ← → ↑ ↓ | キーボードで見回す |
| Tab | マウスのロック（カーソルを隠して見回す）の ON / OFF |
| ESC | 終了 |

ウィンドウを選ぶと、自動でマウスがロックされます（カーソルが消えます）。
ほかのウィンドウに切り替えたときや、終了確認が出たときは自動でロックが外れます。

### カメラの感度・速さを変える
`camera.cpp` の上のほう（「調整用の値」）にまとまっています。

| 値 | 意味 | 初期値 |
|---|---|---|
| `MOUSE_SENSITIVITY` | **マウス感度**。大きいほど速く回る（0.001f〜0.005f くらいが目安） | `0.0025f` |
| `MOUSE_INVERT_Y` | `true` でマウスの上下を逆にする | `false` |
| `KEY_ROTATE_SPEED` | 矢印キーで回る速さ | 2° / フレーム |
| `MOVE_SPEED` | 移動の速さ | `0.15f` / フレーム |
| `RUN_MULTIPLIER` | Shift を押したときの速さの倍率 | `3.0f` |

## ファイルの役割
| ファイル | 役割 |

| `shaderPixel3D.hlsl` | ピクセルシェーダー（色を決める。テクスチャにも対応） |
| `shaderWater.hlsli` | 水のシェーダー共通の定義（定数バッファ b5） |

| `keyboard.h / .cpp` | キーボード入力（押している／押した瞬間／離した瞬間） |
| `mouse.h / .cpp` | マウス入力（Raw Input で移動量を取る、カーソルのロック） |
| `field.h / .cpp` | 湖のある地形。`FieldGetHeight(x, z)` で地面の高さが分かる |
| `water.h / .cpp` | 湖の水面 |
| `cube.h / .cpp` | 立方体のサンプル（インデックスバッファを使う例） |
| `polygon2D.h / .cpp` | 2D（UI）描画のサンプル |
| `debug_ostream.h / .cpp` | `hal::dout << "文字" << std::endl;` で VS の出力ウィンドウに表示 |

## 水のレイトレーシングのしくみ
DirectX 11 にはハードウェアのレイトレーシング（DXR。DirectX 12 の機能）がないので、
水のピクセルシェーダーの中で、光線と物体の当たり判定を自分で計算しています。

水面の1ピクセルごとに：
1. **反射**：カメラからの視線を波打つ水面で跳ね返し、その光線が地形・立方体・空のどれに当たるかを調べる
   - 地形：レイマーチング（光線を少しずつ進めて、地面の下に入った場所を探す）
   - 立方体：スラブ法（光線と箱の当たり判定）
   - 何にも当たらなければ空の色＋太陽のきらめき
2. **屈折**：水の中に曲がって入った光線が湖底に当たるまでの距離を求め、長いほど水の色（青緑）を強くする
3. **フレネル**：水面を浅い角度で見るほど反射を強く、真上から見るほど湖底が見えるように混ぜる

注意：
- **水に映るのは、シェーダーが知っている物（地形と立方体）だけ**です。新しい物を映したいときは、
  `shaderPixelWater.hlsl` にその物の当たり判定を足し、必要な情報を `WaterBuffer`（b5）で渡します。
- 地形の形と色は **`field.cpp` と `shaderPixelWater.hlsl` の両方に同じ式**があります。片方だけ変えると、
  水に映る地形や湖底がずれます。
- カメラは水の中に入れないようにしてあります（水中から見た描画には対応していないため）。

## 新しいオブジェクトを足すとき
`cube.cpp` をコピーして作るのがいちばん早いです。

1. `〇〇Initialize / Finalize / Update / Draw` の4つの関数を作る
2. `main.cpp` の `Initialize`・`Finalize`・`Update`・`Draw` から呼ぶ
3. `Draw` では次の順番で設定してから描く
   - `Shader_SetWorldMatrix(...)` … 位置・回転・大きさ（拡大縮小 → 回転 → 移動 の順に掛ける）
   - `Shader_SetMaterial(...)` … 色
   - 頂点バッファ（とインデックスバッファ）をセットして `Draw` / `DrawIndexed`
4. ファイルを Visual Studio のプロジェクトに追加する（`.vcxproj` が変わるので一緒にコミット）

物を地面の上に置きたいときは、`FieldGetHeight(x, z)` で高さを調べて y に入れます。

## 描画の順番（`main.cpp` の `Draw`）
1. `Clear()` で画面と深度バッファを消す
2. **3D**：`SetDepthEnable(true)` → `CameraDraw()` → ライトON → 地形・立方体を描く
3. **水**：`WaterDraw()`（ほかの3Dのあと。中で水用シェーダーに切り替えて、終わったら戻す）
4. **2D（UI）**：`SetDepthEnable(false)` → ライトOFF → 2Dを描く（描いた順に上に重なる）
5. `Present()` で画面に出す

## 気をつけること
- **ポリゴンの表は時計回り。** 見る側から見て頂点が時計回りに並んでいない面は描かれません（バックフェースカリング）。
- **シェーダーの定数バッファ**は `shader.h` / `shader.cpp` の構造体と `shaderCommon.hlsli` / `shaderWater.hlsli` の並びをそろえること。片方だけ変えると色や位置がおかしくなります。
- **シェーダー（`.hlsl` / `.hlsli`）は BOMなしUTF-8** で保存する。BOM があるとコンパイルが `X3000: Illegal character` で失敗します。
  C++ のファイル（`.cpp` / `.h`）は **BOM付きUTF-8**。
- ビルドすると `.cso`（コンパイル済みのシェーダー）がプロジェクトのフォルダにできます（Git には入れない）。
  exe を直接ダブルクリックすると .cso が見つからずエラーになるので、Visual Studio から実行してください。
